## Cómo usar esto

Si te lo van a revisar en 2 minutos: abre `portada.html`.

Si te van a entrevistar: entra al proyecto que te van a preguntar y ten abierto el índice de verificación. Si te piden el código de SQL o Rust, dilo sin rodeos: no está en esta máquina, pero lo reconstruyes y lo pasas. Mejor eso que inventar un archivo.
